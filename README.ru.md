# magniF

<img src="assets/icon.png" width="96" height="96" alt="Значок magniF">

[English](README.md) · **Русский**

Лупа для Windows 10 (2004+) и 11 по удержанию клавиши. Держите клавишу — прямо под курсором появляется
скруглённая лупа, сам курсор прячется, чтобы не мешать, а лупа ездит за мышью. Отпустили —
лупа исчезла.

## Скачать

Последняя сборка — в [Releases](https://github.com/Solevaral/magniF/releases):

- `magniF-<версия>-win-x64-standalone.exe` — запускается как есть, ничего ставить не нужно.
- `magniF-<версия>-win-x64-net9.exe` — маленький, нужен .NET 9 Desktop Runtime.

Установщика нет: положите файл куда угодно и запустите. Программа живёт в области уведомлений;
окно настроек открывается при первом запуске, по клику на иконку в трее или при повторном
запуске exe.

## Как пользоваться

- **Зажмите бинд** (по умолчанию Ctrl) — после короткой задержки появится лупа.
- **Клавиша продолжает работать как обычно.** Лупа появляется, только если за время задержки
  больше ничего не нажато, поэтому Ctrl+C, Ctrl+клик и прочие сочетания её не вызывают.
- **Клики проходят сквозь лупу** в точку под меткой центра.
- **Колесо мыши** при открытой лупе меняет кратность; новое значение запоминается.
- **Отпустите** — лупа исчезнет, курсор вернётся.

Биндом может быть любая клавиша, сочетание (Ctrl+Shift, Alt+Z…) или кнопка мыши (средняя,
боковые 4/5).

## Настройки

| Раздел | Что настраивается |
|---|---|
| Активация | бинд, задержка появления, зум колесом и его шаг |
| Лупа | кратность, сглаживание, ширина, высота, скругление, метка центра (нет / точка / крест) и её цвет |
| Стиль | цвет и толщина рамки, размер и плотность тени |
| Общее | язык (системный / English / Русский), автозапуск с Windows |

Изменения применяются сразу и видны в живом превью. Настройки хранятся в
`%AppData%\magniF\settings.json`.

## Как устроено

Лупа целиком рисуется на видеокарте, с частотой обновления вашего монитора:

- изображение рабочего стола берётся через **Desktop Duplication API**;
- вывод — прозрачное для мыши окно на весь монитор с цепочкой обмена **DirectComposition**
  и попиксельной прозрачностью;
- один пиксельный шейдер **Direct3D 11** рисует увеличенное изображение (бикубическое или чёткие
  пиксели), скруглённую форму, рамку, тень и метку центра — всё со сглаживанием.

Само окно не двигается — двигается только картинка внутри, поэтому положение лупы и увеличиваемая
область всегда из одного кадра: никаких шлейфов и размазывания. Окно исключено из захвата экрана
(`WDA_EXCLUDEFROMCAPTURE`), так что лупа никогда не увеличивает саму себя.

Нажатия отслеживают низкоуровневые хуки клавиатуры и мыши на отдельном потоке. Курсор прячется
через `MagShowSystemCursor` из Magnification API и возвращается при отпускании, выходе и необработанной ошибке.

## Известные ограничения

- **Игры в эксклюзивном полноэкранном режиме** идут мимо DWM — поверх них лупа не рисуется.
  Оконный и безрамочный режимы работают.
- Пока в фокусе окно, запущенное **от администратора**, Windows не передаёт его ввод хукам
  обычного процесса, и бинд там не срабатывает. Если нужно — запускайте magniF от администратора.
- Запрос UAC и Ctrl+Alt+Del живут на защищённом рабочем столе и не увеличиваются.

## Сборка

```bash
dotnet build magniF.sln -c Release
```

Один файл, нужен .NET 9:

```bash
dotnet publish src/magniF/magniF.csproj -c Release -o publish
```

Один файл, автономный:

```bash
dotnet publish src/magniF/magniF.csproj -c Release -r win-x64 --self-contained true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish-selfcontained
```

Нужен .NET 9 SDK. Целевая платформа — x64.
